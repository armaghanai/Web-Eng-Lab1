# Web Engineering Lab 01

## Overview
This repository contains the practical work completed during **Lab 01** of the CS-344 Web Engineering course. The lab focused on the foundational structure of the web by introducing fundamental HTML element tags, semantic text formatting, heading hierarchies, line breaks, horizontal rules, and embedding external visual assets.

---

## Lab Objectives & Key Concepts

1. Understand the core structure of an HTML document (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
2. Implement semantic document headings (`<h1>` to `<h6>`) to create structured content hierarchies.
3. Manage inline line breaks (`<br>`) and structural thematic breaks (`<hr>`).
4. Embed and render external image assets (`<img>`) using primary attributes like `src` and `alt`.

---

## HTML Tags Covered

| Tag | Full Name | Description / Usage |
| :--- | :--- | :--- |
| `<!DOCTYPE html>` | Document Type Declaration | Informs the browser about the document type and HTML version (HTML5). |
| `<html>` | Root Element | The container for all other HTML elements in the document. |
| `<head>` | Document Head | Contains metadata, document title, scripts, and stylesheet links. |
| `<title>` | Page Title | Sets the title of the webpage displayed in the browser tab. |
| `<body>` | Document Body | Contains all visible content rendered on the webpage. |
| `<h1>` – `<h6>` | Headings | Defines HTML headings. `<h1>` is the highest level (most important), and `<h6>` is the lowest level. |
| `<p>` | Paragraph | Represents a block of text content. |
| `<br>` | Line Break | Produces a single line break in text without starting a new paragraph (Self-closing tag). |
| `<hr>` | Horizontal Rule | Renders a thematic break or horizontal divider between content blocks (Self-closing tag). |
| `<img>` | Image Tag | Embeds an image into the document using `src` for path and `alt` for fallback description (Self-closing tag). |
